# Anexo - Base de Dados

Esta pasta contém a exportação final da base de dados `greenerry` para entrega da PAP.

Ficheiro oficial:

- `greenerry_base_dados_final.sql`

O ficheiro `greenerry.sql` na raiz do projeto foi atualizado com a mesma exportação final, para facilitar a importação durante a demonstração. Se forem feitas alterações novas na base de dados antes da entrega, exportar novamente a base `greenerry` e substituir os dois ficheiros.
