# Anexos - Capturas da Plataforma

Esta pasta guarda capturas finais usadas como apoio ao relatório, ao manual técnico e à preparação do vídeo da PAP.

Ordem recomendada para apresentação:

1. Visitante: homepage, catálogo de música, loja, detalhe de produto e artista público.
2. Cliente: perfil, biblioteca, notificações, encomendas, carrinho e checkout.
3. Artista: dashboard, análises, produtos e lançamentos.
4. Administração: login reservado, dashboard, encomendas, produtos, mensagens e relatórios.

As capturas de progresso visual devem ser usadas apenas para explicar evolução do projeto, não como percurso principal da demonstração.
